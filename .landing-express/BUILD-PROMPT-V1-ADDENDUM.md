# Build Prompt Contract — V1 Addendum

This addendum extends the existing v0 Build Prompt Contract. Preserve all v0 sections and add the following when relevant:

- EXECUTION CONTEXT: GREENFIELD / EVOLUTION / VISUAL REFACTOR / REBUILD.
- VISUAL SYSTEM DIRECTION with explicit styling behavior.
- VISUAL CONTEXT PROFILE derived from the approved editorial/color system.
- MOTION HIERARCHY: PRIMARY / SUPPORTING / AMBIENT.
- ASSET DELIVERY CONTRACTS with required modality/provider/fallback policy.
- VISUAL INTEGRATION CONTRACTS for context-aware asset compositing/integration.
- CAPABILITY REQUIREMENTS with no-silent-fallback policy.
- MODEL / EFFORT RECOMMENDATION.
- PRESERVATION REQUIREMENTS for existing/refined implementations.

V1 binding rules:

1. Required modality is binding; video/frame-sequence cannot silently become a static substitute.
2. Required capability is binding; when fallback is `block`, missing tool stops execution.
3. Visual Integration derives from Visual Context Profile, not a hard-coded dark treatment.
4. Every generated asset keeps the v0 generation budget discipline plus objective retry conditions.
5. Approved existing structure marked PRESERVE must not regress during localized refine/regenerate.
